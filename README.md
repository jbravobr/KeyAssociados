# KeyAssociados — auditoria Hering

> Aplicativo de auditoria desenvolvido para o contexto do projeto Hering.

## Organização

- `Droid/` — projeto da plataforma Android.
- `TechSocial.Test/` — projeto de testes.
- `TechSocial/` — projeto ou módulo `TechSocial`.
- `iOS/` — projeto da plataforma iOS.

Solução: [`TechSocial.sln`](TechSocial.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`TechSocial.sln`](TechSocial.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
